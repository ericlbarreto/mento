# @mento/web — Next.js frontend (UI only)

No API routes here: all data comes from `apps/api` (`NEXT_PUBLIC_API_URL`). Route groups:

| Path | Who | Notes |
|---|---|---|
| `/` (`(student)/page.tsx`) | Person 2 | Start screen (pick student + material) |
| `/session/[id]` | Person 2 | Whiteboard |
| `/professor` | Person 1 | Students tab |
| `/professor/materiais` | Person 1 | Materials tab |

Brand files are in `public/brand/` (logo, mascot, symbol, `mascot/{spin,float,thinking,speaking}.gif`). Tokens: `@mento/ui/tokens.css`.

```bash
pnpm dev:web   # http://localhost:3000
```

## Next.js 16 notes (read before writing pages)

Version pinned: `next@16.4.3` + React 19.2. Full guide: `node_modules/next/dist/docs/01-app/02-guides/upgrading/version-16.md`. What matters here:

| Change | What to do |
|---|---|
| **Async request APIs only** (`params`, `searchParams`, `cookies()`, `headers()` are Promises; sync access removed) | Server Components: `const { id } = await params`. Client Components: `use(params)`. Type helpers: `PageProps`, `LayoutProps` |
| **Turbopack is the default** for `dev` and `build`; a custom `webpack` config is ignored | Do not add webpack config; use the `turbopack` key in `next.config.ts` if ever needed |
| **React 19.2** | Available: `<ViewTransition>` (start screen → orb mascot glide), `useEffectEvent` (stable callbacks in the action queue), `<Activity>` (hide the PDF drawer without losing state) |
| **`next/image`**: local images with a query string need `images.localPatterns.search`; some defaults changed (`qualities`, `imageSizes`, `minimumCacheTTL`) | Use plain `<img>` for the mascot GIFs (stacked, opacity toggles); `next/image` only for static PNGs |
| `scroll-behavior: smooth` is no longer overridden on navigation | Add `data-scroll-behavior="smooth"` on `<html>` only if we set smooth scroll globally |
| Removed: `next lint`, `middleware` (now `proxy`), `serverRuntimeConfig`/`publicRuntimeConfig`, AMP | Lint with `pnpm lint` (ESLint CLI); config via `NEXT_PUBLIC_*` env vars |

`apps/web/AGENTS.md` is generated by `next dev` and only points agents to these docs; keep it committed.
